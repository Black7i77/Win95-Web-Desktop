# Win95 Web Desktop

Browser-based retro Windows 95-style desktop, adapted from the original win95_public project.

## Hosting

Deploy as GitHub Pages from main branch, root folder. No server needed.

## Limitations

The built-in Internet Explorer-style window is a browser iframe: many real websites block embedding. External proxy is deliberately disabled to protect visitor privacy. Dexter AI is a visible demo without a backend on static GitHub Pages. Never place private API keys in publicly hosted HTML.
